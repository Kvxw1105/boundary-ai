# 中国数据保护法律体系速查手册

## 《个人信息保护法》(PIPL) — 2021年11月1日生效

### 关键条款

| 条款 | 内容 | 合规要点 |
|------|------|---------|
| 第4条 | 个人信息定义：以电子或其他方式记录的与已识别或可识别的自然人有关的各种信息 | 匿名化处理后的信息不属于个人信息 |
| 第13条 | 处理个人信息的七种合法基础：同意、合同必要、法定义务、公共卫生、新闻报道、已公开信息、其他 | 至少满足一种合法性基础 |
| 第17条 | 告知义务：处理前需告知处理者名称、联系方式、处理目的、方式、种类、保存期限 | 需以显著方式、清晰易懂的语言告知 |
| 第38-40条 | 数据出境规则：安全评估/标准合同/认证（三选一）+ 个人单独同意 | CIIO + 处理100万人以上个人信息 → 必须安全评估 |
| 第44-50条 | 个人权利：知情权、决定权、查阅权、复制权、更正权、删除权、可携带权、解释说明权 | 接到请求后应及时受理，不得设置不合理条件 |
| 第47条 | 删除权：处理目的已实现/无法实现、停止提供服务、保存期限届满、撤回同意、违法处理 | 需在15个工作日内处理 |
| 第66条 | 罚款上限：5000万元或上年度营业额5% | 严重违法可暂停业务、吊销许可 |

## 《数据安全法》(DSL) — 2021年9月1日生效

| 条款 | 内容 | 合规要点 |
|------|------|---------|
| 第21条 | 数据分类分级制度：国家建立数据分类分级保护制度 | 各地区/部门制定重要数据目录 |
| 第31条 | 重要数据出境：CIIO的重要数据出境需安全评估 | 非CIIO的重要数据出境由国家网信部门会同国务院制定办法 |
| 第36条 | 外国司法/执法机构数据请求：非经主管机关批准，不得提供 | 阻断外国长臂管辖 |

## 《网络安全法》(CSL) — 2017年6月1日生效

| 条款 | 内容 | 合规要点 |
|------|------|---------|
| 第37条 | CIIO的个人信息和重要数据境内存储 | 因业务需要确需出境的，需安全评估 |

## 《数据出境安全评估办法》 — 2022年9月1日生效

### 触发条件（满足任一即需申报）

1. 数据处理者向境外提供**重要数据**
2. **关键信息基础设施运营者**(CIIO)向境外提供个人信息
3. 处理**100万人以上**个人信息的数据处理者向境外提供个人信息
4. 自上年1月1日起累计向境外提供**10万人以上**个人信息或**1万人以上**敏感个人信息

### 申报流程

1. 数据出境风险自评估 → 2. 向省级网信办提交申报 → 3. 省级网信办完备性查验（7工作日）→ 4. 国家网信办受理 → 5. 安全评估（45工作日，可延长）→ 6. 结果通知
- 有效期：2年
- 需重新申报情形：目的/方式/范围变化、接收方变化、法律环境变化、其他影响数据安全的情形

## 《个人信息出境标准合同办法》 — 2023年6月1日生效

- 适用条件：非CIIO + 不涉及重要数据 + 处理个人信息<100万人 + 累计出境<10万人（敏感<1万人）
- 标准合同模板由国家网信办制定发布
- 合同生效后10个工作日内向省级网信办备案

## 《反外国制裁法》 — 2021年6月10日生效

- 第12条：任何组织和个人不得执行或协助执行外国对中国公民/组织的歧视性限制措施
- 第14条：违反前条的，可被列入反制清单

## 《出口管制法》 — 2020年12月1日生效

- 管制物项：两用物项、军品、核、其他相关物项
- 管制方式：出口许可制度
- 域外适用：对管制物项的再出口同样适用
