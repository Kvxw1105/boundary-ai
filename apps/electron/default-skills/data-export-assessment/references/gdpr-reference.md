# GDPR 关键条款速查手册

## 通用数据保护条例 (GDPR) — 2018年5月25日生效

### 核心定义

| 条款 | 内容 |
|------|------|
| 第4(1)条 | 个人数据：与已识别或可识别的自然人相关的任何信息 |
| 第4(7)条 | 数据控制者：决定处理目的和方式的实体 |
| 第4(8)条 | 数据处理者：代表控制者处理个人数据的实体 |
| 第4(11)条 | 同意：数据主体自由、具体、知情且明确的意愿表示 |

### 数据处理合法性基础 (第6条)

1. 数据主体同意
2. 合同履行必要
3. 法定义务
4. 保护数据主体或他人的重大利益
5. 公共利益/职权
6. 控制者或第三方的合法利益（需与数据主体利益平衡）

### 数据主体权利

| 条款 | 权利 | 内容 |
|------|------|------|
| 第12条 | 透明信息 | 简洁、透明、易懂、易于获取 |
| 第15条 | 访问权 | 确认是否处理 + 获取副本 |
| 第16条 | 更正权 | 不准确个人数据的更正 |
| 第17条 | **被遗忘权** | 删除 + 通知第三方 + 搜索引擎去索引 |
| 第18条 | 限制处理权 | 暂时限制处理 |
| 第20条 | **数据可携带权** | 以结构化、通用格式获取并传输 |
| 第21条 | 反对权 | 反对基于合法利益的处理和直接营销 |
| 第22条 | 自动化决策 | 不受制于仅基于自动化处理的决策（含画像） |
| 第77条 | 投诉权 | 向监管机构投诉 |
| 第82条 | 索赔权 | 因违反GDPR造成的损害索赔 |

### 数据跨境传输 (第44-49条)

| 条款 | 内容 | 要点 |
|------|------|------|
| 第45条 | **充分性认定** | 欧盟委员会认定第三国保护水平充分 → 自由传输 |
| 第46条 | **适当保障措施** | SCC、BCR、行为准则、认证机制 |
| 第47条 | **约束性公司规则 (BCR)** | 跨国企业内部传输规则 |
| 第49条 | **特定情形克减** | 明确同意、合同必要、公共利益、法律主张（有限使用） |

### 义务与处罚

| 条款 | 内容 |
|------|------|
| 第25条 | 数据保护设计 & 默认 |
| 第30条 | 处理活动记录 |
| 第33条 | 数据泄露通知（72小时） |
| 第35条 | **数据保护影响评估 (DPIA)** |
| 第37条 | **数据保护官 (DPO)** 任命 |
| 第83(5)条 | 罚款上限：**2000万欧元或全球年营业额4%**（取其高者） |

### Schrems II 判决影响 (2020年7月)

- 欧盟-美国隐私盾 (Privacy Shield) 无效
- SCC可作为传输工具，但需逐案评估（传输影响评估 TIA）
- 必要时需采取补充措施（加密、假名化等）

## EU AI Act (2024年通过，分阶段生效)

### 风险分级

- **不可接受风险**（禁止）：社会评分、实时生物识别监控
- **高风险**：关键基础设施、教育、就业、执法
- **有限风险**：透明度义务（聊天机器人等）
- **最小风险**：无额外义务

### 处罚

- 最高3500万欧元或全球年营业额7%
